# בדיקות ידניות — מה לבדוק שעובד

מסמך פשוט. עובר עליו לפי הסדר, מסמן ✓ או ✗.

**איך מריצים את האפליקציה:**

```bash
pnpm --filter @rastoplan/web dev
```

נפתח ב־http://localhost:5173

---

## חלק 1 — הלבשת תבניות (הכי חשוב)

### 1.1 מלבן פשוט

1. צייר מלבן סגור — 4 קירות.
2. לחץ **חשב**.

- [ ] כל קיר קיבל שורת תבניות אחת
- [ ] בכל פינה יש פאנל פינה (תכלת) עם קו אלכסוני
- [ ] אין ריבועים אדומים
- [ ] אין רווחים בין תבניות

### 1.2 שני קווי מתאר — **הבדיקה המרכזית**

1. צייר מלבן פנימי.
2. צייר מלבן חיצוני סביבו, במרחק 20 ס״מ מכל צד.
3. לחץ **חשב**.
4. **תעשה זום פנימה** על אחד הקירות (גלגלת עכבר).

- [ ] יש שתי שורות תבניות לכל קיר — ירוקה (פנימי) וכחולה (חיצוני)
- [ ] **התפרים בין התבניות נמצאים באותו גובה בשני הצדדים** — קו ישר לרוחב הקיר
- [ ] אותם סוגי תבניות באמצע (למשל R75 מול R75)
- [ ] בקצוות, לצד החיצוני יש תבנית נוספת

> זו הנקודה של ירון. אם התפרים לא בקו אחד — יש בעיה.

### 1.3 קיר שלא מתחלק יפה

1. צייר קיר באורך שלא מתחלק ב־75, למשל 437 ס״מ.
2. לחץ **חשב**.

- [ ] יש מילוי עץ (צהוב) באמצע
- [ ] **מילוי העץ באותו מקום בדיוק בשני הצדדים**

### 1.4 צורת L (פינה נסוגה)

1. צייר צורת L — 6 קירות.
2. צייר קו מתאר שני סביבה.
3. לחץ **חשב**.

- [ ] בפינה שנכנסת פנימה יש פאנל פינה **גם בצד החיצוני**
- [ ] אין ריבועים אדומים
- [ ] אין הודעות שגיאה ב"הערות מנוע"

### 1.5 עוביים שונים

1. צייר מלבן. בחר קיר אחד ושנה עובי ל־25.
2. לחץ **חשב**.

- [ ] הקיר מרוצף נכון
- [ ] הקירות השכנים לא נשברו

## חלק 2 — כמויות

בפאנל הימני, אחרי **חשב**:

- [ ] טבלת פאנלים מציגה **פנימי / חיצוני / סה״כ**
- [ ] פנימי + חיצוני = סה״כ
- [ ] מספר ה־R75 בטבלה = מספר התבניות שרואים על השרטוט
- [ ] פאנל פינה נספר **פעם אחת**, לא פעמיים
- [ ] קלמרות K30 = מספר הפינות החיצוניות × 3

## חלק 3 — חישוב אוטומטי והתרעות

### 3.1 חישוב אוטומטי

1. צייר קיר.
2. **אל תלחץ חשב.** חכה שנייה.

- [ ] החישוב רץ לבד והתבניות הופיעו
- [ ] כפתור **חשב** עדיין עובד ידנית

### 3.2 עריכה ידנית שורדת

1. אחרי חישוב, גרור תבנית אחת למקום אחר.

- [ ] התבנית זזה וצבעה השתנה (כתום = ידני)
- [ ] **החישוב לא רץ מחדש ומחק לך את העריכה**
- [ ] אם נוצרה אי־התאמה — מופיעה הודעה ב"הערות מנוע"

### 3.3 הכרעת כמות ידנית

1. הקלד מספר ידני באחד משדות הכמויות.

- [ ] המספר נשאר גם אחרי חישוב מחדש

## חלק 4 — פרויקטים (בדיקות אובדן מידע)

> אלה הבדיקות הכי חשובות. הבאג הזה אכל עבודה.

### 4.1 מעבר מהיר בין פרויקטים

1. צייר קיר.
2. **מיד** (תוך שנייה) לחץ 📁 פרויקטים ← צור פרויקט חדש.
3. חזור לפרויקט הישן.

- [ ] **הקיר עדיין שם**

### 4.2 פרויקט חדש מתחיל נקי

1. צור פרויקט חדש.

- [ ] אין קירות
- [ ] אין תבניות
- [ ] הכמויות ריקות
- [ ] המסך חזר למרכז (זום ומיקום אופסו)
- [ ] אין שאריות מהפרויקט הקודם

### 4.3 שכפול

1. צייר קיר בפרויקט.
2. **מיד** שכפל את אותו פרויקט.
3. פתח את העותק.

- [ ] הקיר האחרון נמצא גם בעותק

### 4.4 מחיקה

1. מחק את הפרויקט הפתוח.

- [ ] הוא נעלם מהרשימה
- [ ] נפתח פרויקט אחר
- [ ] **הוא לא חזר לרשימה אחרי רענון**

### 4.5 מחוון שמירה

- [ ] בזמן עריכה מופיע "שומר…"
- [ ] אחרי רגע מופיע "נשמר"
- [ ] אם השרת נופל — מופיע "שגיאה"

## חלק 5 — התחברות והרשמה

> רלוונטי רק כשעובדים מול שרת.
> קובץ `packages/web/.env` צריך `VITE_STORAGE_PROVIDER=api`

**להרצת השרת:**

```bash
pnpm --filter @rastoplan/server dev
```

### 5.1 הרשמה

1. פתח את האפליקציה.

- [ ] מופיע מסך התחברות, לא השרטוט
- [ ] לחיצה על "אין לך חשבון? הרשמה" מעבירה למסך הרשמה
- [ ] סיסמה קצרה מ־8 תווים → שגיאה
- [ ] אימייל לא תקין → שגיאה
- [ ] שתי סיסמאות שונות → "הסיסמאות אינן תואמות"
- [ ] הרשמה תקינה → נכנסים לאפליקציה

### 5.2 התחברות

1. התנתק (או פתח חלון גלישה בסתר).

- [ ] סיסמה שגויה → "אימייל או סיסמה שגויים"
- [ ] אימייל לא קיים → **אותה הודעה בדיוק**
- [ ] פרטים נכונים → נכנסים

### 5.3 הרשמה כפולה

- [ ] הרשמה עם אימייל שכבר קיים → "כתובת האימייל כבר רשומה"

### 5.4 בידוד בין משתמשים — **בדיקת אבטחה**

1. הירשם כמשתמש א׳, צור פרויקט, רשום את השם שלו.
2. התנתק.
3. הירשם כמשתמש ב׳ (אימייל אחר).

- [ ] **רשימת הפרויקטים של ב׳ ריקה**
- [ ] הפרויקט של א׳ לא מופיע בשום מקום

4. חזור למשתמש א׳.

- [ ] הפרויקט שלו עדיין שם ולא השתנה

### 5.5 שמירת סשן

1. אחרי התחברות, רענן את הדף (F5).

- [ ] נשארת מחובר, לא צריך להתחבר שוב

## מה עדיין לא נבדק מול הלקוח

הדברים האלה עובדים בקוד, אבל המספרים לא אושרו על ידי ירון:

| נושא | מצב |
|---|---|
| כמות מוטי דיווידאג | רץ על ברירת מחדל (2 למוט). שלושת הגיליונות של הלקוח נותנים מספרים שונים |
| אורך "המוט הארוך" | לא נמסר |
| צומת T | עדיין בלי ציוד פינה |
| פינה נסוגה — קלמרות | לא ברור אם הפאנל הנוסף צורך גם 3 קלמרות |
